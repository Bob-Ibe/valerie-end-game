# Valerie end game

Een klein spelletje. Jij speelt Bob. Valerie heeft laserogen.

Live: https://bob-ibe.github.io/valerie-end-game/

## Hoe het werkt

- Beweeg met je muis, je duim of de pijltjestoetsen, in alle richtingen.
- Hoe verder naar achteren je staat, hoe kleiner je wordt.
- Valerie schiet elke seconde. Ontwijken helpt niet.
- Op de helft van je life pakt ze een bazooka.
- Duur: ongeveer dertien seconden.

## Bouwen

`index.html` is gegenereerd. Pas de bronbestanden in `src/` aan en bouw opnieuw:

```bash
python3 src/build.py
```
